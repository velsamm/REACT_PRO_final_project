# Установка и запуск

Установка зависимостей

```shell
npm install
```


Запуска в режиме разработки

```shell
npm run start:vite
```

# 1. Архитектура и структура

1. Вынесены UI-компоненты без логики в src/shared/ui
2. ButtonBack, LikeButton, LoadMore, Search, Sort вынесены в папку с фичами src/features
3. Добавлены абсолютные пути

# 2. Оптимизация

1. При загрузке после прокрутки списка товаров (CardList) можно заметить ререндеры компонента Card. При большом количестве Card, страница может тормозить (Скриншот CardListBefore.png). После мемоизации Card, количество ререндеров существенно снизилось (Скриншот CardListAfter.png).
2. При добавлении товаров в корзину ререндерятся карточки, которые не относятся к добавленному товару. Чтобы избежать ненужных ререндеров, были мемоизированы компоненты LikeButton, Button, а также  поле isProductInCart и функция handleAddProductToCart в Card (скрин профайлера CardMemoProfile.png).

# 3. React.Portal для модалок

1. В public/index.html добавлен <div id="modal-root"></div>. Создан shared компонент Modal, который рендерится через портал
2. Создан компонент CartModal для демонстрации работы модалки.

# 4. useRef — реальное применение

1. создан хук useClickCounter для подсчета кликов. использован в LikeButton для подсчета кликов лайков каждого товара.
2. в SignInForm использован реф для автофокуса на инпут после начального рендера.

# 5. Собственные сборки (esbuild/swc)

1. Сборка с помощью вебпака заняла 17,5 секунд. общий размер бандла - 650кб (скриншот WebpackBundleInfo.png)
2. Сборка с помощь Vite заняла 5,18 секунд. общий размер бандла - 645кб (скриншот ViteBundleInfo.png)

Вывод: Vite существенно обгоняет Webpack 5 по скорости сборки
